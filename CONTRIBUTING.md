# Contributing

Thank you for considering a contribution to Sylius Live One Page Checkout Plugin.

## Contributor License Agreement

Before we can merge your pull request, you need to accept the Sylius Contributor License
Agreement (CLA). When you open a pull request, the CLA Assistant bot comments with a link to the
agreement. Sign in with GitHub, accept it, and the `license/cla` check turns green. You only need
to do this once.

## Pull requests

1. Fork the repository and create a branch from `main`.
2. Open a pull request against `main`.
